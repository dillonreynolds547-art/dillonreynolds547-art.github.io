Privacy policy

Dynasties Untold Uploader · Last updated 7 October 2026

This policy explains how the Dynasties Untold Uploader (“the app”) handles data. The app is a personal tool used only by the owner of the Dynasties Untold YouTube channel to publish that channel's own videos.

Data the app accesses

When the channel owner signs in with Google, the app requests permission to:

  • Upload videos to the signed-in YouTube channel (scope youtube.upload).
  • View the channel's basic information, used only to show which channel is connected (scope youtube.readonly).

The app does not access Gmail, contacts, files, viewer data, comments, analytics or any other Google data, and it never accesses data belonging to anyone other than the signed-in channel owner.

How the data is used

Access is used solely to upload the channel's own videos with their titles, descriptions and tags, and to confirm the connected channel. Nothing is used for advertising, profiling or any other purpose.

Storage and sharing

The sign-in token Google issues is stored only on the channel owner's own computer. The app has no server and no database; it does not send Google user data to the developer or to any third party, and it does not sell or transfer it.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the Google Privacy Policy.

Removing access and deleting data

Access can be revoked at any time from your Google Account permissions page. Deleting the stored token file from the computer running the app removes all locally stored credentials.

Changes and contact

Any changes to this policy will be posted on this page. Questions can be raised through the site's GitHub page.
